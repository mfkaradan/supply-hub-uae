# ABM Premium Supply

Create a premium, modern, highly professional website for:

ARafa Building Materials (ABM)

A UAE-based building materials supplier.

Website goal:

The website must immediately make it clear to any visitor what ABM does.

ABM supplies quality building materials and construction products to contractors, real estate developers, retailers, businesses and individual customers. ABM focuses on reliable product sourcing, timely delivery, custom orders, expert material guidance and professional customer service.

IMPORTANT:

Do NOT make the website look like a generic construction company website.

ABM is primarily a BUILDING MATERIALS SUPPLIER / TRADING COMPANY, not a construction contractor.

The design should be inspired by clean, modern UAE corporate websites:

- Very clean

- Professional

- Premium

- Easy to understand

- Strong typography

- Plenty of white space

- Minimal but impressive animations

- No unnecessary decorative elements

- No excessive gradients

- No clutter

- No huge blocks of text

--------------------------------------------------

BRAND

--------------------------------------------------

Primary brand color:

DESIGN DIRECTION

--------------------------------------------------

Create a high-end corporate website similar in visual quality to a modern UAE business website.

The first impression should communicate:

QUALITY

RELIABILITY

SUPPLY

PROFESSIONAL SERVICE

Use large clean typography with short, powerful headlines.

Use real architectural / construction-material photography.

Use premium images showing:

- Modern UAE architecture

- Construction sites

- Delivery/logistics

Images should have a consistent cinematic and premium photographic style.

--------------------------------------------------

ANIMATIONS

--------------------------------------------------

Use subtle professional animations only.

Examples:

- Smooth page entrance

- Fade-up text

- Image reveal animations

- Slight image parallax

- Number counting animation

- Smooth hover effects

- Button arrow movement

- Card hover elevation

- Staggered appearance of service cards

Do NOT use:

- Excessive bouncing

- Flashing

- Overly complicated animations

- Continuous distracting movement

The website should feel premium, not like an animation demo.
